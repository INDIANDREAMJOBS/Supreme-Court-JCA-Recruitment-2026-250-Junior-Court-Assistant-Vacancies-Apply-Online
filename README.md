| Parameter | Details |

| **Organization** | Supreme Court of India (SCI Registry) |
| **Post Name** | Junior Court Assistant (JCA) |
| **Total Vacancies** | **250 Posts** |
| **Classification** | Group 'B' Non-Gazetted |
| **Pay Scale** | Level 6 Pay Matrix (₹35,400 – ₹1,12,400) (~₹65,000/month gross) |
| **Educational Qualification** | **Bachelor's Degree (Graduation)** + English Typing (35 wpm) + Computer Knowledge |
| **Age Limit** | **18 to 30 Years** (Relaxation: OBC +3 yrs, SC/ST +5 yrs, PwBD +10 yrs) |
| **Application Fee** | ₹500 (General/OBC) \| ₹250 (SC/ST/Ex-Servicemen/PwBD) |

---

## 🎯 Selection Process & Exam Pattern

1. **Objective Written Test**: 100 MCQs (General English 50, Aptitude 25, GK 25) — **120 Mins**, **-0.25 Negative Marking**.
2. **Computer Typing Test**: 35 wpm in English on Computer (**10 Mins**, max 3% errors allowed).
3. **Descriptive Paper**: English Comprehension, Precis Writing & Essay (**2 Hours**).
4. **Personal Interview**: Final viva-voce stage conducted by Supreme Court Interview Board.
